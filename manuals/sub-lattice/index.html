BRK - Sub Lattice

User manual and parameter reference · 1.4.1

A polyphonic subtractive synthesizer with two oscillators, two filters and a 16-slot modulation matrix.

Quick start

  1. Insert Sub Lattice on an instrument track and play MIDI notes, or use its keyboard.
  2. Load a factory preset from the name menu, or start with Init.
  3. Turn down a filter cutoff and add an envelope-to-cutoff matrix route to hear the filter move.

Editor window

980 × 995 minimum; resizable. Dimensions are logical editor pixels, before host window chrome. HELP adds 92 pixels of height (Gear adds a one-pixel divider too). Allow enough usable screen space at your display scale. Press HELP again to close the help area.

Operation

Each oscillator supplies its main waveform and a sub oscillator. Tune, Fine and octave controls set pitch; Shape changes the waveform, while FM, Feedback, Ring and the modulation mode add more complex spectra. Oscillator volume and filter balance decide where each source goes.

The two filters can run in series or parallel. Model chooses the circuit; Variant, response and slope depend on that model. Cutoff sets the frequency, resonance emphasizes the boundary, key tracking follows played pitch and drive changes the filter input character.

Amp controls the note level. The three modulation envelopes supply additional movement. Attack rises to the peak, Decay approaches Sustain and Release falls after note-off. Curve controls change each segment, and Sync converts times to note divisions.

The three LFOs offer Free, Sync and Audio rate modes, plus start phase, delay, ramp and retrigger/DAW-phase behavior. A custom waveform can be drawn. The modulation matrix connects sources to targets with an amount, optional Via source, curve and polarity.

Voices, Mono/Legato, Glide, Master Tune, bend range and the MIDI keyboard govern performance. Advanced settings include quality, oscillator/filter options, MPE, modulation interpretation and sync-note choices. Advanced settings belong to the host session and user defaults; loading a sound preset leaves them unchanged.

Use HELP for the hovered or focused control and Manual / PDF for this reference. Tab reaches named controls, arrows adjust values and Return operates focused choices. Envelope and custom-shape drawing still requires a pointer. The minimum editor size is 980 by 995 pixels.

Presets and files

Presets are browsed with the arrows or the preset-name menu. A star marks an edited patch. Save supports folders, Rename, Delete and opening the user preset folder; dropping a compatible preset file onto the bar loads it. A newer-file indication means this version could not apply every setting.

The host session stores the complete patch. A product preset can deliberately leave listening trim, audition or display controls unchanged; the product-specific rules below describe those exceptions.

User presets use .sublattice in ~/Library/Audio/Presets/Barakigal Audio/Sub Lattice. Sub Lattice presets include Output but leave Advanced settings unchanged. Sessions retain Advanced settings and custom LFO shapes. Very early presets without choice IDs retain their original index interpretation; older modulation mappings may need checking.

Installation and help

Download the macOS archive from the product page and quit your audio host. Place the AU .component in ~/Library/Audio/Plug-Ins/Components, VST3 in ~/Library/Audio/Plug-Ins/VST3, or CLAP in ~/Library/Audio/Plug-Ins/CLAP. The product page also offers an installer with format selection. Restart or rescan the host. To uninstall, quit the host and remove that product's bundles from those folders; saved sessions and user presets are separate.

For questions or a problem report, use BRK Audio support on GitHub. Include the plugin version, macOS version, host and format, sample rate and a short description of how to reproduce it.
