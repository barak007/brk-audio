BRK - Sub Lattice

A synth for sounds that keep moving.

Build basses, leads and pads, then give them movement. Blend two oscillators, explore the filters and draw your own modulation shapes, with the connections always in view.

Download for macOS

Or install from Terminal

curl -fsSL https://github.com/barak007/brk-audio/releases/download/sub-lattice-v1.4.1/install.sh | bash
What this does

Downloads the release archive from GitHub, checks it against the checksum fixed at release time and copies the chosen formats into ~/Library/Audio/Plug-Ins. Installs in your own plugin folders without sudo, refreshes the Audio Unit list when AU is selected, and replaces each installed format only once its new bundle is fully copied.

To read the script first, download it and open it in TextEdit (this runs nothing):

curl -fsSL https://github.com/barak007/brk-audio/releases/download/sub-lattice-v1.4.1/install.sh -o install.sh && open -e install.sh

1.4.02026-11-10
  • Added toggleable contextual HELP and a website/PDF parameter manual without rearranging the synthesizer.
  • Report the amp release tail to hosts, including tempo-synchronized release times.
  • VoiceOver names every knob, value box and mod matrix control ("Slot 3 Target"), and reads the waveform and choice tiles, the on/off tiles and the Filter, Envelope and LFO tabs and the preset bar as controls it can press, so every page can be reached without a mouse; Tab reaches them, the arrow keys move a focused knob (Shift finer) and Return presses a focused tile. The mouse works as before.
  • The LFO view, and the playhead on a Custom LFO's shape, glide while a note plays (most visible in DAW phase mode and with synced rates), instead of stepping by the host's audio block: they move on the screen's refresh at the LFO's rate, following the audio.
  • In DAW phase mode the LFO view keeps scrolling with the song between notes, instead of jumping to the still note-on picture in every gap, and a Custom LFO's playhead stays on its shape.
1.3.02026-11-05
  • Choices (waves, filter models, matrix sources and targets, LFO shapes, note modes and the Advanced settings) are saved by a stable ID beside their index, in presets, sessions and the Advanced defaults file, so they keep their settings when a list gains or moves entries. Files saved before are read as they always were.
  • Choices can no longer be automated by the host, which drops any automation already recorded on them (a host stores a choice as its place in the list, which a new entry would move). Knobs and on/off switches stay automatable.
  • MPE, Sync Dotted and Sync Triplets on the Advanced page are on/off toggles instead of two-entry choices; they look and click the same, stay out of automation like the rest of that page, and sessions keep their values.
1.2.02026-11-04
  • Keyboard: dark square keys in the panel's cell look, a brighter line at every octave, and held notes (played or from MIDI) lit in orange along the top and down the key.
  • Header: Glide and Output take less width, so the output scope is wider.
  • Look: the flat cell look of Good Kick and Rampa. Panels sit edge to edge split by one-pixel lines, every tile, box, menu and tooltip is square, a selected tile is raised with its colour along the top, the displays run to the panel edges and the header is a row of cells. The panels stand apart on the background, each framed by a line.
  • Knob rows are 2 px shorter and the knobs at the foot of the filter, envelope and LFO panels sit closer; the smallest window is now 980 x 954 px, and a new instance opens at that size.
  • The window has a resize grip in its bottom-right corner.
  • Matrix: in a narrow window the Via, curve shape and Polarity columns narrow first, so the Target keeps room for its names.
1.1.02026-11-01
  • Modulation targets: each oscillator's FM amount and the Glide Time (in ms, so a route glides with the knob at 0); the matrix's Target menu groups the targets in submenus (Osc 1, Osc 2, Filter 1, ..., LFO). Sessions saved before keep their routes.
  • Layout: the amp envelope moves into the envelope panel as its first tab (Amp, Env 1, Env 2, Env 3) and the modulation matrix gets its own panel beside the filter; each oscillator's Drift is a value box under Phase, Tune and Fine, and Pan sits next to Volume; the waveform tiles are shorter, naming each wave in small text in the corner, so the filter, matrix, envelope and LFO panels are taller; the filter's serial/parallel toggle sits between the Filter 1 and Filter 2 tabs, its slope, variant and response tiles take less width (long variant names wrap onto two rows), and a knob title like "Drive: Soft" shrinks to fit a narrow slot instead of being cut off.
  • The preset bar sits under the title, so the output scope fills the header's height; the filter and amp panels are the same height as the envelope and LFO panels, so the window is 32 px shorter (1180 x 1028 by default, 968 tall at the smallest); the oscillator panels are titled Osc 1 and Osc 2 without the accent dot.
  • Osc 1 and Osc 2 are matrix sources: an oscillator's own output modulates any target at audio rate (filter FM, audio-rate pan, shape or volume), and the oscillator runs for the route even with its Volume at 0.
  • Each LFO's Rate is a matrix target, in octaves (+/-4 at full), so one LFO or envelope can speed up another.
  • FM and Feedback are true phase modulation: the wave runs backwards when the modulation falls faster than it advances, with the corners it passes either way band-limited, so FM stays in tune (it ran sharp before) and much cleaner. The modulation is updated at the oscillators' own (2x) rate, and Feedback averages the last two samples, as the DX7 does, so it stays clean to about 85% before turning noisy.
  • Linear FM: a toggle beside each FM knob makes the other oscillator modulate the frequency instead of the phase, through zero at high amounts (the analog through-zero FM sound); saw and square modulators stay much cleaner. Switching it mid-note crossfades over 20 ms instead of clicking.
  • Exp FM: a second toggle beside the FM knob gives the modulation an exponential (volts-per-octave) law, so the other oscillator pushes the wave far further up than down: the harsh analog FM sound, under Linear FM or phase modulation. Low amounts sound the same; the difference grows with the knob. Switching it mid-note crossfades too.
  • FM Style on the Advanced page: True PM (the new FM above) or Original, the 1.0 FM exactly, which stays smooth with saws and squares in the FM path where true phase modulation jumps with their edges. Sessions saved before this version open in Original, so they sound as they did.
  • Fixed: Zero-Cross stealing no longer drops the new note when the old one fades out before its zero crossing, and lifting the sustain pedal no longer releases a note that is waiting for its zero crossing.
  • Fixed: a chord that steals more than four voices at once fades every stolen note instead of cutting some.
  • Fixed: Sync Window stays on at 1x, so a sync sweep that lands on 1x no longer clicks.
  • Fixed: Tube and Rect drive no longer click when the Drive is modulated or automated through 0.
  • Fixed: with Sync Window on, moving the Fold or Bits amount no longer brings back the restart buzz.
  • Fixed: the Organ wave with Sync no longer aliases from drawbars above Nyquist.
  • Fixed: slow S&H and Smooth Random LFOs with a Random start no longer run fast or freeze.
  • Fixed: opening a project no longer marks it as modified in the host.
  • Fixed: Delay Comp changes reach the host without locking or allocating on the audio thread.
  • Fixed: a host that reports 0 BPM no longer gives synced times infinite lengths.
  • Fixed: a session saved without drawn LFO shapes now resets the shapes instead of keeping the current ones.
  • Fixed: double-clicking an envelope point or curve dot resets it.
  • Fixed: a blank tooltip box no longer appears when pages switch.
  • Fixed: the Advanced page fits at the smallest window height (MPE moved to the right column).
  • Fixed: the filter tiles and title show the comb polarity or MS-20 response that actually plays when a choice is left over from another model, and the filter curve follows Filter 2x.
  • Fixed: the Custom LFO tile redraws when a preset or session loads a new shape.
  • Fixed: typing a synced time that is not a note value leaves the knob where it was instead of setting 0.
  • The Advanced page no longer reads the settings file 30 times a second, and the modulation dots scan the matrix once per refresh.
  • Presets run on the preset manager shared with Feedline and Good Kick, so they gain its improvements; presets, sessions and the presets folder are unchanged.
  • Presets: your presets can live in folders (submenus in the list; type Folder/Name when saving), Rename is in the preset menu, saving over another preset asks first, a preset file dropped on the preset bar loads, and a preset made with a newer version is marked newer. Loading a preset sets each control once, straight to its value.
